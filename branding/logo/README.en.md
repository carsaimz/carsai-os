## Important note

This icon is a **quality placeholder**: the official artwork will be
provided later. When that happens, simply replace the `carsai-os-icon.svg`
file keeping the same name — no other part of the repository needs to be
changed.

## Requirements for the official artwork

- SVG format (vector), square, dark background compatible with the Neon
  theme.
- Legible at 16 px (favicon) and at 512 px.
- Reference palette of the default theme: cyan `#00E5FF` and magenta
  `#FF2EC4` on a dark background `#0B0B14`.
